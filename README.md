# Customer Support Case Resolution Simulation

This project simulates the daily workflow of a customer support team handling support tickets, resolving customer issues, and analysing performance metrics.

## Project Overview

The purpose of this project is to demonstrate how customer support operations function in a real environment using ticket management, issue classification, and resolution tracking.

The project includes:

• 100 realistic customer support tickets  
• Ticket lifecycle simulation  
• Issue categorisation and prioritisation  
• Resolution tracking and escalation handling  
• Customer satisfaction scoring  
• Performance analysis of support operations  

## Project Files

Contains analysis of support performance metrics such as response time, resolution rate, and ticket distribution.
